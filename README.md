### Проект 1. Тестирование приложения Mesto



#### Учебный проект по тестированию веб-приложения Mesto.



Выполненные задачи:



* Проведение регрессионного тестирования по готовым тест-кейсам.



* Ретестирование ранее обнаруженных дефектов.



* Проверка соответствия фактических результатов ожидаемым.



* Документирование результатов тестирования.



Цель проекта: получение практического опыта в ручном тестировании веб-приложений, работе с тестовой документацией и выявлении дефектов.



Направление: Manual QA / Functional Testing.
